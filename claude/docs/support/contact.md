## Before Contacting Support

Save time by trying these first:

### 1. Check the Documentation
- [FAQ](faq.md) - Common questions
- [Installation Guide](../getting-started/installation.md)
- [Quick Start](../getting-started/quickstart.md)
- [Feature Docs](../pricing-comparison.md)

### 2. Search Existing Issues
- [WordPress.org Forum](https://wordpress.org/support/plugin/zsoogi-clipper/)
- [GitHub Issues](https://github.com/TheAPIGuysDev/zsoogi-clipper/issues)

### 3. Try Basic Troubleshooting
- Deactivate other plugins to test for conflicts
- Switch to a default WordPress theme
- Check PHP error logs
- Clear browser cache
- Try a different browser

### 4. Gather Information
Before contacting support, collect:
- WordPress version
- PHP version
- Zsoogi Clipper version
- Active theme
- Active plugins
- Error messages (exact text)
- Screenshots of the issue
- Steps to reproduce

## Tips for Getting Help Faster

### Write a Clear Subject Line
❌ "It doesn't work"
✅ "Bookmarklet not capturing selected text on Chrome"

### Provide Context
- What were you trying to do?
- What did you expect to happen?
- What actually happened?
- When did this start?

### Include Screenshots
A picture is worth 1000 words. Use screenshots to show:
- Error messages
- Console errors (F12 in browser)
- Settings configuration
- The issue in action

### Be Patient and Polite
Our support team is here to help! Being courteous leads to faster, better support.
