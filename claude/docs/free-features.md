## What You Get

### Core Features

#### 1. Bookmarklet Content Capture
- **Text Selection Capture:** Select any text on a webpage and capture it as a formatted blockquote
- **URL & Title Capture:** Automatically captures the page URL and title for proper citation
- **Image Capture:** Automatically detects and captures the first meaningful image from the page
- **One-Click Operation:** Install the bookmarklet once, then capture content with a single click

#### 2. YouTube Integration
- **Title Cleanup:** Automatically removes view counts and "- YouTube" suffix from titles
- **High-Quality Thumbnails:** Fetches `maxresdefault.jpg` quality thumbnails from YouTube
- **Clean Citations:** Properly formatted YouTube video references

#### 3. Custom Post Type
- **Zsoogi Clips Post Type:** Dedicated custom post type for captured content
- **Custom Taxonomy:** Single "Zsoogi Type" taxonomy for basic organization
- **WordPress REST API:** Full REST API support for custom integrations
- **Standard WordPress Features:** Comments, revisions, featured images

#### 4. Security & Privacy
- **Administrator-Only Access:** Non-admin users cannot view Zsoogi clips (redirected to homepage)
- **Private Research:** Keep your web research private from site visitors
- **WordPress Security Standards:** Built with WordPress security best practices

#### 5. Content Formatting
- **Simple Citation Format:** `Source: [Title](URL)` format for clean references
- **Blockquote Styling:** Captured text formatted as WordPress blockquotes
- **Notes Section:** Automatic "Notes" heading for adding your own commentary
- **WordPress Block Editor:** Full Gutenberg block support

#### 6. Auto-Featured Images
- **Automatic Image Setting:** Captured images automatically set as featured images
- **Configurable:** Toggle auto-featured image on/off in settings
- **Smart Detection:** Filters out icons, logos, and small avatars (minimum 200px)

#### 7. Basic Settings
- **Settings Page:** Clean, simple settings interface
- **Auto-Featured Image Toggle:** Enable/disable automatic featured image setting
- **Include Metadata Option:** Add capture date/time to clips
- **Bookmarklet Installation Page:** Easy drag-and-drop installation instructions

## How to Get It

### Installation

1. **From WordPress.org:**
    - Go to WordPress Admin → Plugins → Add New
    - Search for "Zsoogi Clipper"
    - Click "Install Now" then "Activate"

2. **Manual Installation:**
    - Download from [wordpress.org/plugins/zsoogi-clipper](https://wordpress.org/plugins/zsoogi-clipper)
    - Upload to `/wp-content/plugins/` directory
    - Activate through the WordPress Plugins menu

### Setup

1. Navigate to **Zsoogi Clips → Grab Zsoogi** in WordPress admin
2. Drag the bookmarklet button to your browser's bookmarks bar
3. Visit any webpage and click the bookmarklet to capture content
4. Configure settings at **Zsoogi Clips → Settings**

## Frequently Asked Questions

### Is it really free forever?
Yes! The Community edition is 100% free and always will be. It's GPL-licensed open source software.

### Do I need to create an account?
No account needed. Just install from WordPress.org like any other plugin.

### Can I use this on multiple sites?
Yes! Install on as many WordPress sites as you want.

### Will my data be collected?
No. The free version does not collect any usage data or analytics. Your content stays on your server.

### Can I upgrade later without losing data?
Absolutely! All your captured clips will remain intact when upgrading to Premium or Enterprise.

### What happens if I switch to another theme?
Zsoogi Clipper works with any WordPress theme. It uses standard WordPress post types and blocks.
